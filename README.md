# Homebrew tap for pyhttp

[pyhttp](https://pyhttp.com) — a local API client and alternative to Postman, with a collection runner, scripts, mock servers and an MCP server. Free for everyone under the [pyhttp Free License 1.1](https://github.com/pyhttp2/pyhttp/blob/main/LICENSE.md).

```sh
# macOS (Apple Silicon): the desktop app bundle
brew install --cask pyhttp2/pyhttp/pyhttp

# macOS (Intel or ARM) and Linux: the pyhttp command (Python package, no app bundle)
brew install pyhttp2/pyhttp/pyhttp
```

No `brew tap` needed — the commands above tap this repository automatically. The cask and formula are updated by the [release workflow](https://github.com/pyhttp2/pyhttp) on every release.

- Source and issues: https://github.com/pyhttp2/pyhttp
- Downloads and previous versions: https://github.com/pyhttp2/pyhttp/releases (older releases: [pyhttp-releases](https://github.com/pyhttp2/pyhttp-releases))
